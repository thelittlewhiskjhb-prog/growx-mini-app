# GROWX Futuristic Latest

Latest free front-end prototype.

Included:
- Futuristic neon/3D visual design
- Smooth page-to-page transitions
- Registration: cellphone + 4-digit PIN + confirmation
- Login: cellphone + 4-digit PIN
- Letters-only client code display
- Customer dashboard
- All eight requested package displays and daily reward UI
- Daily reward activation button
- Wallet/activity
- Bank name + account number + account holder
- Bank withdrawal
- USDT withdrawal, network and wallet address
- Separate admin dashboard
- Client search/account view
- Admin allocation-recording interface
- Withdrawal queue oldest → newest

Important: this is a static prototype for free GitHub Pages hosting. It is not a secure backend and must not be used to collect real PINs, banking details, wallet addresses, balances, or process real financial transactions. Real-money operation requires secure server-side authentication/database, audit controls and appropriate legal/compliance arrangements.
