# GROWX Mini App — V1 UI Prototype

A colorful, futuristic Telegram Mini App front-end prototype.

## Important
This version is **UI/demo only**:
- no real authentication
- no real database
- no real deposits
- no real withdrawals
- no real reward settlement
- no financial transaction is performed

The displayed package values are prototype configuration based on the requested catalogue.

## Files
- `index.html` — Mini App screens
- `styles.css` — 3D/futuristic visual system
- `app.js` — demo interactions and package catalogue
