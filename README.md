# GROWX Free Launch Prototype

This package contains the latest free front-end prototype for GitHub Pages.

Included:
- Customer welcome screen
- New member registration: cellphone + 4-digit PIN + confirmation
- Existing member login: cellphone + 4-digit PIN
- Unique letters-only client code display
- Customer dashboard
- Requested package catalogue and daily-reward UI
- Daily reward activation button
- Wallet
- Bank details
- Bank withdrawal
- USDT withdrawal with network and wallet-address fields
- Separate restricted admin dashboard
- Client search/account view
- Masked banking information
- Demo account-allocation workflow with transaction reference
- Withdrawal queue ordered oldest → newest

Important:
GitHub Pages is suitable for this free visual prototype. It is not a secure backend. Do not use this static prototype to collect real PINs, banking details, wallet addresses, balances, or to process real-money/USDT transactions. A secure server-side backend, authentication, database, audit logging and appropriate legal/compliance controls are required before real financial operation.
