# GROWX USD / USDT UI Update

Updated static front-end prototype.

Changes:
- Currency changed from ZAR to USD.
- Package catalogue changed to: $20, $40, $80, $120, $200, $450, $700, $1,000, $2,000, $3,000.
- Daily reward display is calculated at 10% of package value:
  $20 → $2/day
  $40 → $4/day
  $80 → $8/day
  $120 → $12/day
  $200 → $20/day
  $450 → $45/day
  $700 → $70/day
  $1,000 → $100/day
  $2,000 → $200/day
  $3,000 → $300/day
- Removed bank account/details and bank withdrawal UI.
- USDT withdrawal is TRON/TRC20 only.
- Added USDT recharge page with instructions; no deposit address is displayed.
- Added dashboard daily reward CLAIM button.
- Added Redeem Gift Code page.
- Added a futuristic 7-day reward performance graph.
- Added persistent bottom navigation icons.

Important:
This remains a static front-end prototype. It does not process cryptocurrency, create real balances, authenticate securely, or verify transactions. A real-money implementation requires a secure server-side system, proper transaction verification, custody/payment controls, and applicable legal/compliance review.
